# 问题首页和精简行业地图

首页改为 `/home`，根路径自动跳转。六个问题覆盖模型/产品发布、真机演示、客户试点、商业部署/量产、技术成果、融资合作。每张卡的数字来自真实保存事件，点击查看企业、时间、阶段和原始引文，不用固定答案填充。

支持7天、30天、全部时间；事件日期优先于文章日期。未知日期和未来日期不计入最近窗口。独立验证/客户确认可单独筛选，但系统不会将企业自述升级。试点/商业部署问题依据已提取阶段，单纯发布公告或阶段未知不计入已发生部署。记录数可能包含重复报道。

以2026-11-02数据验证：共398条事件，其中47条匹配最近30个UTC日期。六类问题分别匹配8、4、5、4、7、9条记录，分类可以重叠。这只是数据库覆盖范围，并不是整个行业的发生数量。

地图 `/industry` 默认企业卡片，每页8家，支持企业名称/别名搜索、技术方向多选、发展阶段筛选。公司按记录数排列，不是竞争力排名。可选最多4家切换精简矩阵，冻结左侧方向列，避免25家公司铺成巨大横表；每个数字仍可展开事件和原文证据。空格仅表示没有匹配记录。支持重置筛选。

原有企业档案、行业动态、产品能力对比、来源发现入口保留；首页导航移到首位。没有改动数据库或触发额外模型调用。

验证：6项前端语义测试覆盖时间窗口、未知/未来日期、发生时间优先级、演示与试点区分、规划不算已部署；运行 `cd frontend; npm test`。TypeScript和生产构建通过。本地 `/home`、`/industry` HTTP200，并使用同一前端筛选函数核对了真实API数据。未执行浏览器自动化视觉检查。

产品后续优先项：跨报道去重、关注企业列表及时间线中的新旧变化提示。它们比继续增加概览数字更有助于用户快速定位值得跟进的事实。
